# E 成员：后台管理功能交付记录（第二轮）

完成日期：2026-08-20

分支：`feature/E-admin-management-round-2`

## 已交付

- 审批页新增请假审批区域：
  - 支持请假通过和拒绝，拒绝时必须填写原因（前端预校验 + 服务端 422）。
  - 支持按待审批/全部过滤，展示学生、课次、时间和联系电话。
  - 已审批请假不能重复审批（服务端 409）。
- 排课页支持新增课次：
  - 新增表单含校区、班级、课程、教师、日期、起止时间和教室。
  - 班级/课程/教师按所选校区过滤。
  - 排课失败时保留表单内容，不关闭表单。
- 排课页支持修改课次：
  - 修改时间、教室和教师，时间校验结束必须晚于开始。
  - 成功后使用服务端返回值更新页面。
- 排课页支持取消课次：
  - 取消后状态变为 `CANCELLED`，操作按钮隐藏。
- 用户页支持账号启停：
  - 启停入口只对系统管理员显示。
  - 禁止停用当前登录的系统管理员。
  - 成功后用服务端返回值更新账号状态。
- 数据范围：
  - 教务只能管理所属校区的请假和排课。
  - 系统管理员可以查看全部校区。
- 状态处理：
  - 新增加载中、空数据、冲突和重试状态。
  - `401` 清理 Token 回登录；`403`/`409`/`422` 显示服务端错误，不修改本地状态。
  - 网络错误归类为 `NETWORK_ERROR`，不清理 Token。

## 接入的接口（由 A 第二轮契约定义）

| 方法与路径 | 用途 |
|---|---|
| `PATCH /admin/leave-requests/:leaveRequestId/review` | 请假审批（`decision` + `reviewNote`） |
| `POST /admin/schedules` | 新增课次 |
| `PATCH /admin/schedules/:scheduleId` | 修改或取消课次（`status: 'CANCELLED'`） |
| `PATCH /admin/users/:userId` | 账号启停（`active`） |
| `GET /admin/overview` | 返回 `leaveRequests` 字段 |
