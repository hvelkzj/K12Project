- 调课审批、代课安排、课次更新和家长通知联动。

## 权限结果

| 角色 | 后端范围 |
|---|---|
| 家长 | 已绑定学生 |
| 学生 | 当前学生本人 |
| 任课教师 | 本人授课班级和本人发布内容 |
| 班主任 | 可查看负责班级；教学写操作仍要求本人授课 |
| 教务 | 所属校区 |
| 系统管理员 | 全部校区 |

所有操作者 ID 均从当前会话生成。请求体中的伪造身份字段不会覆盖服务端身份。

## 业务边界

- 重复请假、提交、签到、调课、审批、批改和工单操作返回 `409`。
- 未绑定学生、非本人课程和跨校区访问返回 `403`。
- 字段、时间、附件、分数和必填内容错误返回 `422`。
- 作业订正新增 `attempt`，旧记录不覆盖。
- 不允许迟交的作业在截止后拒绝提交。
- 代课教师必须同校区、不能是原教师且不能时间冲突。
- 已取消课次不能继续请假、签到、发布作业、发送反馈或申请调课；停用账号不能被安排代课。
- 拒绝调课必须填写原因；关闭工单必须先开始处理并填写结果。

## 数据重置

业务仓库在 API 进程启动时创建。重启 API 即恢复初始状态。自动测试为每个场景创建独立仓库，不依赖测试顺序。
