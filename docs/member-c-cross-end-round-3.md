## 真实 API 联调结果（本地 `http://127.0.0.1:3000`，21 项全部通过）

- 教师 `teacher_301` 登录并发布新作业 → 学生 `student_101` 从真实 API 读取到该作业。
- 学生首次提交（attempt 1）→ 教师端概览可读取该提交。
- 教师要求订正（`REVISION_REQUIRED`，70 分 + 评语）→ 学生刷新概览看到分数和评语。
- 学生订正提交（attempt 2）→ 概览展示完整历史 `attempts=[1,2]`。
- 教师批改订正稿（`GRADED`，92 分 + 评语）→ 学生查看最终批改结果。
- 边界：重复提交返回 `409`；发布限时作业过期后提交返回 `409 作业已截止`；空正文空附件返回 `422`；无效 Token 返回 `401`。
- 账号停用：管理员停用 `student_101` 后，已有会话 `401` 失效且不能重新登录；恢复后可以正常登录。

## 修复的学生端问题

1. **提交结果页不再短暂显示"暂无提交记录"**：此前提交成功依赖概览重载完成后才更新结果页，重载失败会一直错误显示无记录。现在结果页优先展示本次提交的服务端返回值，重载完成后自动与概览一致。
2. **attempt 历史展示完整**：历史列表从"次数 · 状态 · 时间"扩展为每次提交的正文、得分和老师评语，订正流程中旧记录仍可完整查看，草稿不会覆盖服务端历史。
