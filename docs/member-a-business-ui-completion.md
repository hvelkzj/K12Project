# A 跨端业务功能完善交付

日期：2026-08-24。

## 交付内容

- 公共层增加业务状态中文标签，家长、学生、教师和后台不再直接显示英文状态代码。
- API 增加学生/教师附件上传和统一认证下载，真实文件字节保存在可重置的内存仓库。
- 后端校验文件类型、大小、上传人和业务数据范围，拒绝越权下载与伪造附件元数据。
- 学生端可以下载课件、作业和本人提交附件，提交附件改为真实上传。
- 教师端可以上传作业附件；批改页可以打开学生提交详情，查看正文并下载附件。
- 后台隐藏英文角色代码和路由路径，统一显示中文身份与业务状态。

## 业务验收

| 场景 | 结果 |
|---|---|
| 家长查看待处理反馈 | 显示“待家长确认” |
| 教师上传并发布附件作业 | 成功，学生刷新后立即可见 |
| 学生下载教师附件 | 成功取得真实二进制内容并按原名保存 |
| 教师查看学生提交 | 可查看正文、提交次数、时间、状态和附件 |
| 教师下载学生附件 | 成功取得本人作业对应提交文件 |
| 越权下载或伪造附件 | 后端拒绝 |
