# 参考产品

只用于参考页面和基本操作，不需要提交调研报告。

| 产品 | 参考内容 | 相关成员 |
|---|---|---|
| [校宝智慧校园](https://www.xiaobaoonline.com/products/sis.html) | 排课、调课、考勤、家长通知、后台权限 | A、B、D、E |
| [ClassIn](https://www.classin.com/k12/) | 课程、课件、作业提交和教师批改 | C、D |
| [钉钉家校本](https://page.dingtalk.com/wow/dingtalk/act/clashomework?wh_biz=tm) | 作业发布、完成统计和提醒 | B、C、D |
| [Moodle 作业](https://docs.moodle.org/502/en/Assignment_activity) | 作业提交和批改状态 | C、D |

使用方式：

- A、E 主要参考校宝的后台结构。
- B 主要参考校宝家长端和钉钉通知。
- C 主要参考 ClassIn 的学生作业页面。
- D 主要参考 ClassIn 和钉钉的教师操作。

不需要完整复制产品，也不实现直播、支付、营销和硬件功能。
