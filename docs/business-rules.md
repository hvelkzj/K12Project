# 核心业务规则与权限

## 调课/请假状态

`DRAFT → SUBMITTED → APPROVED/REJECTED → SUBSTITUTE_ASSIGNED → PARENT_NOTIFIED → CONFIRMED → COMPLETED`。

教师提交请假后不可自行修改已审批记录；教务审批时必须填写原因。审批通过后系统仅推荐满足课程、时间和班级要求的教师，教务最终确认。家长未确认时显示待确认，不阻塞教务继续记录电话确认。紧急调课可由教务强制发布，但必须填写原因并生成审计记录。

## 家校反馈工单

`DRAFT → SENT → ACKNOWLEDGED/DISPUTED → CS_PROCESSING → FOLLOW_UP → CLOSED`。

家长提出异议后，班主任只能补充说明，不能删除原记录；教务客服可要求补充证据、安排回访、调整跟进状态。超过 48 小时未处理自动标记超时并进入教务待办。关闭前必须填写处理结论，家长可在关闭后重新发起关联工单。

## 权限隔离

| 角色 | 数据范围 | 关键权限 |
|---|---|---|
| 家长 | 自己及绑定学生 | 查看课表/通知、请假、反馈确认/异议 |
| 学生 | 自己 | 查看课件、提交作业、查看批改 |
| 教师 | 自己授课班级 | 签到、反馈、批改、发起请假 |
| 班主任 | 负责班级全量跟进 | 查看完整学生跟进、回复异议 |
| 教务 | 所属校区 | 排课、审批、代课、处理工单 |
| 系统总管 | 全机构 | 组织、账号、角色、审计、全局看板 |

所有查询都必须带数据范围条件，不能仅靠前端隐藏按钮实现权限控制。
