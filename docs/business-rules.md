# 核心业务规则

## 调课流程

`教师提交 → 教务审批 → 安排代课 → 通知家长 → 完成`

- 教务拒绝时必须填写原因。
- 安排代课时检查教师时间是否冲突。
- 家长可以查看调课前后的时间和教师。
- 已审批的申请不能由教师直接修改。

## 家校反馈

`教师发送 → 家长确认/提出异议 → 教务处理 → 关闭`

- 教师填写学生表现、优点、不足和建议。
- 家长提出异议后保留原反馈。
- 教务填写处理结果后才能关闭。

## 作业流程

`教师发布 → 学生提交 → 教师批改 → 学生查看`

- 截止后默认不能提交。
- 教师可以要求学生订正后重新提交。

## 权限

| 角色 | 数据范围 |
|---|---|
| 家长 | 自己绑定的学生 |
| 学生 | 自己的数据 |
| 教师 | 自己授课的班级 |
| 班主任 | 自己负责的班级 |
| 教务 | 所属校区 |
| 系统管理员 | 全部校区 |

权限必须由后端检查，不能只隐藏前端按钮。
