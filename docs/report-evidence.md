# 实验报告证据清单

| 报告部分 | 开发期间必须保存的材料 |
|---|---|
| 功能介绍 | 每端功能树、角色说明、关键页面截图 |
| 交互概要 | `docs/ai-log/` 中按阶段整理的提示词、回复摘要、人工判断 |
| 系统设计 | ER 图、权限矩阵、调课/工单状态图、API 调用关系 |
| 测试与调试 | 单元/集成/压力结果、失败日志、修复前后对比 |
| 使用示例 | 每张截图配操作前提、步骤、页面状态和预期结果 |
| 团队合作 | PR、Issue、接口文档、三类提交记录截图、迁移同步记录 |
| 完整过程 | `AGENTS.md`、规则文件、skills 配置和完整 AI 交互记录 |

## 必留测试场景

- 教师请假被拒、审批通过但无合适代课教师、家长未确认、教务紧急强制发布。
- 家长重复提交异议、48 小时超时、客服补充证据后关闭、关闭后重新关联。
- 教师访问其他班级、家长访问非绑定学生、教务访问其他校区、普通角色尝试修改审计记录。
- 作业重复提交、附件过大、网络中断重试、批改后学生端刷新。
