## 发现与修复

1. Node.js 24 在 Windows 启动时报告 `DEP0190`。原因是子进程启用了 `shell: true`。
2. 统一启动已改为由当前 Node.js 进程调用 `npm_execpath`，不再经过 shell。
3. 增加共享层回归测试，防止重新引入 shell 启动。
4. 首次依赖审计发现 3 个高危公告。普通 `npm audit fix` 更新 4 个间接依赖补丁版本，未使用 `--force`，复查为 0 漏洞。
