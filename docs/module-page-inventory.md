## 运行时约定

- 五个前端中的业务数据均来自 API；统一入口只保存展示配置和项目截图。
- 学生端 `mockData.ts` 仅作为测试夹具，不被运行时页面引用。
- 本地测试账号用于真实认证 API，不是前端业务数据源。
- 五个前端共用 `@k12/shared` 的数字 ID、camelCase 字段和大写状态。
- 仅保留根目录 `package-lock.json`。
