## 运行时约定

- 六个工作区的业务数据均来自统一服务；统一入口只保存展示配置和项目截图。
- 学生端 `mockData.ts` 仅作为测试夹具，不被运行时页面引用。
- 本地测试账号用于真实认证 API，不是前端业务数据源。
- 网页端、APP 和小程序共用 `@k12/shared` 的数字 ID、camelCase 字段、大写状态和 `StudentOverview`。
- 页面把角色和业务状态代码统一转换为中文，不直接展示英文枚举。
- 附件通过认证接口传输真实字节，不再只展示元数据或假下载提示。
- 仅保留根目录 `package-lock.json`。
