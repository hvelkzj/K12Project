## 集成约定

- 页面使用现有 Vue 3 + TypeScript 工作区，不额外引入路由或 UI 框架。
- 页面导航使用单页 Mock 状态，后续接入 API 时再确定 URL 路由。
- 公共字段使用 camelCase、数字 ID 和 `docs/api-field-contract.md` 中的大写状态。
- 仅保留根目录 `package-lock.json`。
- macOS 终端和 Windows PowerShell 均运行 `npm ci`、`npm run check`。
