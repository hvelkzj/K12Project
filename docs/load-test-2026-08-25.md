# 统一服务压力测试记录

日期：2026-08-25

## 方法

- 命令：`npm run test:load`
- 服务：脚本启动独立的进程内仓库和本机回环 HTTP 服务，结束后关闭端口。
- 登录：家长、学生、任课教师、班主任、教务和系统管理员六类账号分别登录并复用会话。
- 请求：家长、学生、教师和后台概览共 500 次。
- 并发：最高 50。
- 权限：另执行 4 个跨角色访问探针，均应返回 `403`。
- 判定：不设置依赖设备性能的固定耗时门槛；要求服务不中断、失败数为 0、越权探针全部被拒绝。

## macOS 结果

| 指标 | 结果 |
|---|---:|
| 请求数 | 500 |
| 最高并发 | 50 |
| 吞吐量 | 5760.16 请求/秒 |
| 平均耗时 | 8.35 ms |
| P50 | 3.96 ms |
| P95 | 48.33 ms |
| 最大耗时 | 81.59 ms |
| 失败数 | 0 |
| 越权探针 | 4/4 被拒绝 |

结论：当前测试环境下服务保持可用，未出现非预期错误或越权响应。耗时数据仅作为本次设备记录，不作为其他设备的硬性门槛。

## 最终发布复验

最终合并前再次执行同一脚本：500 次请求、最高并发 50、失败 0，4/4 个越权探针均被拒绝。实测吞吐量为 6449.64 请求/秒，平均 7.46 ms，P50 为 3.65 ms，P95 为 42.39 ms，最大 72.71 ms。结果继续满足服务不中断、无非预期错误和无越权响应的判定条件。
