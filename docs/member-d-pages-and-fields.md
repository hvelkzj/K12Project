## 数据范围

| 角色 | 可查看 | 不可查看 |
|---|---|---|
| 任课教师 | 本人授课课程、这些课程的学生、作业、签到和反馈 | 其他教师课程和未授课班级 |
| 班主任 | 本人负责班级的学生与班级信息；本人授课课程可执行教学操作 | 其他班主任负责的班级；非本人授课课程的签到、发布和批改 |

后端必须检查数据范围。前端隐藏入口不能替代权限校验。

## 公共关联字段

以下关联数据应复用 A 发布的公共类型。D 不另建同名字段。

| 含义 | 建议字段 | 用途 |
|---|---|---|
| 记录编号 | `id` | 签到、作业、反馈和调课记录主键 |
| 校区 | `campusId` | 后端校区范围校验 |
| 班级 | `classId` | 课程和学生范围校验 |
| 课程 | `courseId` | 作业和反馈所属课程 |
| 排课 | `scheduleId` | 签到、反馈和调课的原课程 |
| 教师 | `teacherId` | 授课教师或操作人 |
| 学生 | `studentId` | 签到、提交和反馈对象 |
| 创建时间 | `createdAt` | 操作记录追踪 |
| 更新时间 | `updatedAt` | 页面刷新和重复修改判断 |

需要 A 确认实际命名、ID 类型和时间格式。

## 签到字段

| 字段提案 | 类型 | 必填 | 来源 | 说明 |
|---|---|---|---|---|
| `id` | ID | 是 | 后端 | 签到记录编号 |
| `scheduleId` | ID | 是 | 今日课程 | 排课编号 |
| `studentId` | ID | 是 | 课程学生 | 学生编号 |
| `attendanceStatus` | 枚举 | 是 | 教师 | 建议含出勤、迟到、缺勤、请假 |
| `checkedAt` | 日期时间 | 是 | 后端 | 实际登记时间 |
| `checkedBy` | ID | 是 | 当前用户 | 操作教师编号 |
| `remark` | 字符串 | 否 | 教师 | 迟到时长或其他说明 |

重复签到建议由后端使用 `scheduleId + studentId` 校验，并返回已有记录，不由前端生成第二条记录。

## 作业发布字段

| 字段提案 | 类型 | 必填 | 来源 | 说明 |
|---|---|---|---|---|
| `id` | ID | 是 | 后端 | 作业编号 |
| `classId` | ID | 是 | 教师课程 | 发布班级 |
| `courseId` | ID | 是 | 教师课程 | 所属课程 |
| `scheduleId` | ID | 否 | 今日课程 | 关联的具体课次 |
| `title` | 字符串 | 是 | 教师 | 作业标题 |
| `content` | 字符串 | 是 | 教师 | 作业说明 |
| `attachments` | 附件数组 | 否 | 教师 | 复用 C 与 A 确认的附件结构 |
| `deadline` | 日期时间 | 是 | 教师 | 提交截止时间 |
| `allowLateSubmission` | 布尔值 | 是 | 教师 | 是否允许迟交 |
| `publishedBy` | ID | 是 | 当前用户 | 发布教师编号 |
| `publishedAt` | 日期时间 | 是 | 后端 | 实际发布时间 |

`attachments`、作业状态和时间格式必须与 C 确认后再接入。

## 批改字段

| 字段提案 | 类型 | 必填 | 来源 | 说明 |
|---|---|---|---|---|
| `submissionId` | ID | 是 | 学生提交 | C 负责的提交记录编号 |
| `score` | 数字 | 否 | 教师 | 分数；范围由作业规则决定 |
| `comment` | 字符串 | 否 | 教师 | 批改评语 |
| `correctionRequired` | 布尔值 | 是 | 教师 | 是否要求订正 |
| `gradedBy` | ID | 是 | 当前用户 | 批改教师编号 |
| `gradedAt` | 日期时间 | 是 | 后端 | 批改时间 |

提交状态、批改状态、订正次数和重新提交关系由 C 提案，D 只消费同一套字段。

## 课后反馈字段

| 字段提案 | 类型 | 必填 | 来源 | 说明 |
|---|---|---|---|---|
| `id` | ID | 是 | 后端 | 反馈编号 |
| `scheduleId` | ID | 是 | 今日课程 | 反馈对应课次 |
| `studentId` | ID | 是 | 课程学生 | 反馈对象 |
| `teacherId` | ID | 是 | 当前用户 | 发送教师 |
| `performance` | 字符串 | 是 | 教师 | 课堂表现 |
| `strengths` | 字符串 | 是 | 教师 | 学生优点 |
| `improvements` | 字符串 | 是 | 教师 | 待提升内容 |
| `suggestion` | 字符串 | 是 | 教师 | 学习建议 |
| `sentAt` | 日期时间 | 是 | 后端 | 发送时间 |
| `status` | 枚举 | 是 | 流程 | 待确认、家长确认、家长异议、处理中、已关闭等状态待确认 |

家长确认和异议字段由 B 负责，教务处理字段由 E 负责。D 需要读取处理结果，但不维护这些字段。

## 调课申请字段

| 字段提案 | 类型 | 必填 | 来源 | 说明 |
|---|---|---|---|---|
| `id` | ID | 是 | 后端 | 调课申请编号 |
| `scheduleId` | ID | 是 | 今日课程 | 原排课编号，原时间和教师由此读取 |
| `applicantId` | ID | 是 | 当前用户 | 申请教师编号 |
| `requestedStartAt` | 日期时间 | 是 | 教师 | 申请的新开始时间 |
| `requestedEndAt` | 日期时间 | 是 | 教师 | 申请的新结束时间 |
| `reason` | 字符串 | 是 | 教师 | 调课原因 |
| `submittedAt` | 日期时间 | 是 | 后端 | 提交时间 |
| `status` | 枚举 | 是 | 审批流程 | 待审批、已通过、已拒绝等状态待 E 确认 |

审批意见、审批人、代课教师和家长通知由 E、B 负责。D 页面只读这些结果。原课程时间、原教师和教室从 `scheduleId` 对应的公共排课读取，避免重复保存。
