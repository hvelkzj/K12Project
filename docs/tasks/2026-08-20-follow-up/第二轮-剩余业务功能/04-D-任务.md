# D 成员第二轮任务

分支：`feature/D-teacher-leave-round-2`

## 修改范围

- `apps/teacher-web`
- D 交付记录和 AI 记录

不得修改 API、公共类型或其他前端。

## 任务

1. 使用教师 overview 中的 `leaveRequests`。
2. 在签到页面显示学生请假状态。
3. 已批准请假的学生默认使用 `LEAVE`。
4. 已批准请假的学生不能被误记为 `PRESENT`、`LATE` 或 `ABSENT`。
5. 待审批请假只显示提醒，不自动改变签到状态。
6. 被拒绝请假不影响正常签到。
7. 教师只能查看本人授课课次相关请假。
8. 班主任可以查看负责班级请假，但不能替其他教师提交签到。
9. 课次取消后禁用签到、作业、反馈和调课。
10. 错误响应不得修改签到列表。

## 必须测试

- 请假通过、待审批和拒绝。
- 已批准请假对应 `LEAVE`。
- 教师和班主任数据范围。
- 其他教师不能提交签到。
- 已取消课次不能写入。
- `403`、`409` 和网络错误。
