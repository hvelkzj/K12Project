# C 成员第二轮任务

分支：`feature/C-student-workflow-round-2`

## 修改范围

- `apps/student-web`
- C 交付记录和 AI 记录

不得修改 API、公共类型或其他前端。

## 任务

1. 增加全部、未提交、已提交、已批改、需订正五种作业筛选。
2. 增加课程筛选和课件标题搜索。
3. 作业正文和附件元数据保存为本地草稿，并按作业 ID 隔离。
4. 提交成功后清除对应草稿。
5. 提交失败、返回列表或刷新页面时保留草稿。
6. 订正草稿不能覆盖首次提交历史。
7. 课件附件只展示元数据，不显示虚假下载成功。
8. 空作业、空课件和筛选无结果时显示明确状态。
9. 保留 `AssignmentList.vue` 主视觉，不重新设计页面。

## 必须测试

- 状态和课程组合筛选。
- 课件搜索。
- 多作业草稿隔离。
- 提交成功清理草稿。
- 提交失败保留草稿。
- 订正历史不被草稿覆盖。
- 空数据状态。
