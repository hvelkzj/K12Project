# A 成员第二轮任务

分支：`feature/A-management-api-round-2`

## 修改范围

- `apps/api`
- `packages/shared`，仅在确实需要公共字段时修改
- 公共 API 契约
- A 交付记录和 AI 记录

不得修改四个前端。

## 任务

1. 实现 `PATCH /parent/notifications/:notificationId/read`。
2. 在后台和教师 overview 中增加 `leaveRequests`。
3. 实现 `PATCH /admin/leave-requests/:leaveRequestId/review`。
4. 实现排课新增、修改和取消接口。
5. 实现 `PATCH /admin/users/:userId` 账号启停接口。
6. 教务只能审批和维护所属校区数据；系统管理员可以操作全部校区。
7. 账号启停只允许系统管理员，且不能停用当前系统管理员。
8. 停用账号后撤销该账号全部会话，并阻止再次登录。
9. 排课校验校区归属、时间先后、教师冲突、班级冲突和取消状态。
10. 请假审批校验校区范围、重复审批和拒绝原因。
11. 通知只能由对应家长读取和标记。
12. 所有测试使用独立仓库和可注入时钟。

## 必须测试

- 通知已读和越权访问。
- 请假通过、拒绝、重复审批和跨校区。
- 排课创建、冲突、修改和取消。
- 账号停用、会话失效、禁止重新登录和禁止停用自己。
- 六角色权限。

## 提交前运行

```text
npm run test --workspace @k12/api
npm run typecheck --workspace @k12/api
npm run build --workspace @k12/api
npm run check
```

PR 中说明公共契约、共享类型、认证会话和四端接口影响。
