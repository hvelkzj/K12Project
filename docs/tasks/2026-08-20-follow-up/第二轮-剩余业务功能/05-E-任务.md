# E 成员第二轮任务

分支：`feature/E-admin-management-round-2`

## 修改范围

- `apps/admin-web`
- E 交付记录和 AI 记录

不得修改 API、公共类型或其他前端。

## 任务

1. 审批页面增加请假审批区域。
2. 支持请假通过和拒绝，拒绝时必须填写原因。
3. 排课页面支持新增课次。
4. 支持修改时间、教室和教师。
5. 支持取消课次。
6. 排课失败时保留表单内容。
7. 用户页面支持账号启停。
8. 账号启停入口只对系统管理员显示。
9. 教务只能管理所属校区的请假和排课。
10. 系统管理员可以查看全部校区。
11. 成功后使用服务端响应更新页面；失败时不得修改本地状态。
12. 增加加载中、空数据、冲突和重试状态。

## 必须测试

- 请假通过、拒绝原因和重复审批。
- 排课创建、时间冲突、修改和取消。
- 教务跨校区限制。
- 系统管理员账号启停。
- 禁止停用当前系统管理员。
- `401`、`403`、`409`、`422` 和网络错误。

npm run check
