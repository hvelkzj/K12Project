# A 成员第三轮任务

分支：`feature/A-cross-end-round-3`

## 任务

1. 为作业发布、提交、批改和订正增加完整集成测试。
2. 为调课审批、代课、家长通知和通知已读增加完整集成测试。
3. 为教师反馈、家长异议和后台工单增加完整集成测试。
4. 为家长请假、后台审批和教师签到增加完整集成测试。
5. 为后台排课变更和教师 overview 更新增加测试。
6. 为账号停用、会话失效和禁止重新登录增加测试。
7. 每条流程使用独立业务仓库和固定时钟。
8. 覆盖越权、跨校区、重复操作和状态冲突。
9. 只修复 API、共享类型和公共契约问题，不修改四个前端。
