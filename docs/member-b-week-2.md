# 成员 B 第二周交付记录

## 负责范围

家长端和通知。

## 本周目标

完成家长端主要功能，至少完成一条可操作流程。

## 完成内容

- 家长登录与退出
- 首页待办概览
- 学生切换
- 课表查看
- 请假提交
- 请假历史查看
- 通知中心筛选和标记已读
- 反馈确认和提出异议

## 可操作流程

`登录 -> 切换学生 -> 查看课表 -> 提交请假 -> 查看请假历史`

## 补充功能

- 首页显示今日课次、未读通知、待确认反馈和请假记录
- 调课通知展示原时间、新时间和代课教师
- 家长只能查看已绑定学生数据
- 通知可标记已读
- 通知可按全部、未读、调课通知筛选
- 反馈异议需要填写说明

## 测试场景

- 家长账号可登录
- 错误账号不可登录
- 家长只能访问已绑定学生
- 家长可以提交请假
- 家长可以查看请假历史
- 家长可以标记通知为已读
- 家长可以确认反馈
- 家长可以填写说明后提出异议
