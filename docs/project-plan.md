# 项目分工与四周计划

截止时间：2026-08-27。开发时间为 7 月 27 日至 8 月 23 日，最后四天用于整理报告和演示。

## 功能范围

1. 家长端：课表、请假、通知、学生反馈。
2. 学生端：课件、作业提交、批改结果。
3. 教师/班主任端：签到、作业、反馈、请假和调课。
4. 教务后台：排课、审批、代课和反馈工单。
5. 系统后台：机构、账号、角色、权限和数据看板。

支付、营销、直播、人脸识别等功能不做。

## 五人分工

| 成员 | 负责内容 | 主要交付 |
|---|---|---|
| A | 公共架构、数据库、登录权限、集成 | 数据库、登录接口、权限、公共类型、项目整合 |
| B | 家长端和通知 | 课表、请假、通知、反馈确认与异议 |
| C | 学生端和作业 | 课件、作业提交、批改结果 |
| D | 教师/班主任端 | 签到、发布和批改作业、课后反馈、调课申请 |
| E | 教务和系统后台 | 排课、审批、代课、反馈工单、账号和看板 |

每人负责自己模块的页面、接口联调、测试和报告材料。

## 四周计划

| 时间 | 目标 | 验收 |
|---|---|---|
| 第1周 7/27–8/2 | 确定需求、数据库和页面骨架 | 五端可启动，各角色可登录，接口字段确定 |
| 第2周 8/3–8/9 | 完成各端主要功能 | 每端至少完成一条可操作流程 |
| 第3周 8/10–8/16 | 完成跨端联动 | 调课、反馈、作业三条流程可以跨端演示 |
| 第4周 8/17–8/23 | 测试和修复 | 主要异常场景通过，准备截图和演示数据 |
| 8/24–8/27 | 报告和答辩 | 完成报告、演示和最终版本 |

第一周的具体任务和依赖见 [第一周执行计划](week-1-execution-plan.md)。
