# K12 教育培训综合管理平台

五人协作完成的课程项目，包含家长、学生、教师/班主任、教务和系统后台。

## 核心功能

- 排课与调课：教师申请，教务审批并安排代课，家长收到通知。
- 家校反馈：教师填写反馈，家长确认或提出异议，教务处理。
- 作业：教师发布和批改，学生提交并查看结果。
- 权限：不同角色只能查看和操作自己范围内的数据。
